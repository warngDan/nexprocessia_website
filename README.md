# NexProcess IA — site vitrine

Site statique HTML / CSS / JavaScript destiné à Cloudflare Pages.

## Publication
Le dépôt GitHub est relié à Cloudflare Pages. Après chaque `git push` sur `main`, Cloudflare reconstruit et publie le site.

## Structure
- `index.html` : accueil
- `nos-agents-ia.html` : présentation des catégories d'agents
- `automatisation.html` : automatisation des processus
- `a-propos.html` : approche et principes
- `contact.html` : formulaire de démonstration
- `css/style.css` : styles responsive
- `js/script.js` : menu mobile et interactions

## À finaliser avant mise en production commerciale
- Connecter le formulaire à un service de réception (par exemple Make / endpoint sécurisé).
- Ajouter les coordonnées professionnelles validées.
- Rédiger les mentions légales et la politique de confidentialité adaptées à l'activité réelle.
- Vérifier les textes, les offres, les tarifs et les engagements.
- Ajouter des cas clients uniquement lorsqu'ils sont réels et autorisés.


Logo : symbole NexProcess IA intégré dans l’en-tête et le pied de page, avec un dégradé bleu/cyan assorti au site. Fichier : `assets/nexprocessia-mark.png`.
